Typography

Logo typeface: Bauhaus logo only

The "bin ghalib" wordmark is drawn in Bauhaus: heavy, monoline, round bowls, a single-storey a and g. The Group Profile embeds the face as Bauhaus-Bold for the "ENTERPRISES" descriptor in the Binghalib Engineering lockup. In the Group logo itself the letters are outlined. Treat Bauhaus as locked to the logo. Never set headlines, body copy or new company names in it, and never retype the wordmark. Always use the supplied logo artwork. ITC Bauhaus is a commercial typeface, so the website doesn't load it as a webfont. confirm cut & licence (ITC Bauhaus Demi/Bold)

BauhausLogo only · supplied as artwork · not a webfont

Brand typeface: Outfit

Headlines, UI and body copy are set in Outfit. It's an open-source geometric sans (SIL Open Font License 1.1) and a single variable font from Thin to Black, bundled with this hub. Its round bowls and single-storey a echo the Bauhaus wordmark without imitating it, so the logo still stands apart. The Group Profile set its text in Poppins, which remains an approved fallback for existing print templates.

Shares the Bauhaus-era roots and makes elegant headings. Its small x-height and long ascenders make body text and figures like "13,000 A" harder to read at UI sizes.

Recommendation: Outfit for H1–H6, UI and body, with the logo kept as Bauhaus artwork. Set H1 at 700 with −2% tracking, H2/H3 at 600–700, and body at 400, 16/1.6. Avoid weights below 300 on dark backgrounds. Urbanist was also tested and rejected: its body copy is too light.
