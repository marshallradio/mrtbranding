Voice & writing

Translation guidelines

English on the own store is the source. Translate every buyer-facing string for the other locales. Keep product names in Latin letters. Use the glossary. Copy every number. Do not invent a second synonym.

Names that stay in Latin letters

Copy these character for character. Translate only the common noun around them.

  • Marshall GPS, Turbo GPS, Field Marshall, PocketLink, AeroVision, EZ Twist, Marshall Radio, RT, Micro, Scout, PowerMax, Trackpack, Desert Case, Direct Connect, Plan B, FM500 / FM2000 / FM4000 / FM5000, Yagi, Bewit, VHF, UHF, GPS, RF, SMA, SMB, LiPo, Bluetooth, LED, USB

Never write GPS Marshall, GPS Turbo, Feldmarschall, حقل مارشال, Pocketlink, or 中继器. PocketLink is a data receiver, never a repeater.

Arabic titles use جهاز الاستقبال Field Marshall and جهاز استقبال البيانات PocketLink. The transmitter product is ريشة تتبع, not جهاز إرسال.

Beeping frequency and the two ranges

The “beep” or “beeping frequency” on a transmitter is the telemetry radio signal that a Field Marshall direction-finds. It is not an audio tone in hertz.

Use the RF phrase from the glossary. Do not call the three power-on confirmation chirps the beeping frequency.

On Turbo GPS keep both ranges when the English lists both:

  • Data range: 2 to 100 miles (with high-gain omni)
  • RF tracking range: 5 to 200 miles (direction-finding the telemetry beep)

Do not merge them. Do not convert miles to kilometres.

Hard rules

  • Copy every number (grams, inches, miles, days, years, MHz) exactly. Never round or convert units unless the English already did.
  • When the English changes, re-translate in the same session. Clear the Shopify “outdated” flag only after the translation matches.
  • Do not add a specification that is not in the English field. Do not drop a number or one of the two ranges to make the sentence smoother.
  • Keep the radio-licence sentence. The user is responsible for the rules in their country. Never promise a band is licence-free.
  • Title pattern: translated noun + locked product name + remaining spec. Example: receptor de seguimiento UHF Field Marshall.

Review checklist

  1. Title, SEO title and SEO description present; SEO title keeps | Marshall Radio.
  2. Body, feature highlights, device descriptions, FAQs, configurator labels and option values all present.
  3. Every number from the English is present.
  4. Every product name is present in Latin script, exact casing.
  5. No sentence exists only in English.
  6. Register matches the locale (du / tú / tu / je / vy / вы / ですます / 您 / MSA imperative).
  7. Locale is in scope for the product’s markets.
  8. Shopify outdated flag cleared only after the translation matches the current English.
