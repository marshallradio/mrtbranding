Translation

Marshall Radio Telemetry brand guidelines for AI agents · /agents/translation.md
Use when: Translating any catalog copy, product page, collection, option, metaobject or metafield.
Rules that always apply: /AGENTS.md

Locales

English on the own Shopify store is the single source of truth. Do not translate English. French only when explicitly requested. Arabic only for GCC catalog products.

Names that stay in Latin letters

Copy these character for character. Translate only the common noun around them: Marshall GPS, Turbo GPS, Field Marshall, PocketLink, AeroVision, EZ Twist, Marshall Radio, RT, Micro, Scout, PowerMax, Trackpack, Desert Case, Direct Connect, and related tokens (VHF, UHF, GPS, RF, etc.).

Never reorder or transliterate product names. PocketLink is a data receiver, never a repeater.

Glossary

Use the exact term from the glossary in translation.md. Do not invent synonyms. Key examples:

  • transmitter → ريشة تتبع (ar) / Sender (de) / transmisor (es) / 发射头 (zh-CN)
  • receiver → جهاز الاستقبال (ar) / Empfänger (de) / receptor (es)
  • RF beep / beeping frequency → the telemetry radio signal (use the full RF phrase per language)

Hard rules

  • Copy every number exactly. Never convert miles to kilometres or round figures.
  • Keep both Turbo GPS ranges when the English lists both (data range and RF tracking range).
  • When the English changes, re-translate in the same session and clear the outdated flag only after it matches.
  • Title pattern: translated noun + locked name + remaining spec.
