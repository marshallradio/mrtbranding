# Typography

Marshall Radio Telemetry brand guidelines for AI agents · `/agents/typography.md`
Use when: Setting any text.
Rules that always apply: `/AGENTS.md`

## Typefaces
- All text (headings, body and UI): **Matter** by Displaay Type Foundry, Matter Regular (400) and Matter Bold (700). `font-family: "Matter", "Helvetica Neue", Helvetica, Arial, sans-serif`.
- Headings, H3, labels and emphasis use Matter Bold 700; body and UI text use Matter Regular 400. No other weights.
- Code and data: system monospace (`Menlo, Monaco, Consolas, "Courier New", monospace`, the theme's stack).
- The logo lettering is custom italic artwork. Never retype "Marshall" or "RADIO TELEMETRY" in a font to imitate the logo.
- Licensing: Matter is a commercial typeface by Displaay Type Foundry (displaay.net). Its embedded license forbids storing the font files on publicly accessible servers, modifying or redistributing them, so this public site does not host them: browsers use an installed copy of Matter if present, otherwise the fallback stack. Web embedding needs a Displaay web license (https://displaay.net/about/licenses/).
- Office documents: use installed Matter when licensed on that machine; otherwise fall back to Helvetica Neue or Arial. Never embed or share the font files.

## Rules
- Sentence case for new headings. All-caps only for short labels, with 0.1em letter spacing.
- Emphasis by weight, not by color. One display line per layout.
