V2 / V3 comparison

Full side-by-side of the current V2 system and a proposed V3 direction. Arcs stay the single identity; colors, elements, and type are refined.

Color palette

V2 · Current

Deep navy and brick red. Khaki as a secondary surface. Heavier overall.

V3 · Proposed

Cleaner blue, brighter signal red, lighter stone and warm white. Higher contrast, quieter luxury.

Color profiles & pairings

V2
Blue text on Khaki
Light Grey on Blue
White on Black
Brick red for accents

Avoid Blue on Red or Blue on Black for text. Contrast target ≥ 4.5:1.

V3
Refined Blue on Warm White or Stone
Light text on Refined Blue
White on Near Black
Signal Red only for emphasis or errors

Same contrast rules. Prefer outline treatments. Red is brighter and used more sparingly.

How to use the arcs

V2
• Large and faint (white or light grey)
• One per layout only
• Cropped, running off the edge
• Never small, repeated, or outlined
• Often a soft photo overlay

Works as atmosphere but can feel soft and inherited from older assets.

V3
• Single thin vector stroke
• Very low opacity (4–8%)
• Refined Blue or near-black on light; white on dark
• Large, cropped, never filled
• One per layout; never a pattern

Same rules, sharper execution. Reads as intentional signal rather than leftover decoration.

Typography

V2
Display 42px
Heading 22px
Body 16px / 1.6. Matter Regular.

Matter Regular 400 and Bold 700 only. Optional tighter tracking on large sizes (−0.03em).

V3
Display 42px
Heading 22px
Body 16px / 1.65. Slightly more open.

Same faces and weights. Slightly open line-height on body. Tracking kept tight only on display sizes.

Working comparison only. Current guidelines remain in place until a direction is approved.
