Product UI Principles

Rules for any interface that carries the Marshall Radio brand.

  • Light is default. Dark for high-focus or photographic contexts.
  • One primary action per view.
  • Touch targets ≥ 44×44 px. Focus rings always visible.
  • Primary buttons: solid Primary Blue, white text, large radius.
  • Forms: labels above fields, clear error states (text + icon).
  • Hover interactions desktop-only.
