Website design guidelines

Visual system for the Marshall Radio storefront. Helvetica LT Pro Bold for titles, Source Sans Pro for body and UI. Based on the website design guideline.

Blue is the only chromatic accent. Use for primary buttons and action links.

Typography

Display title 60px
Heading 40px
Body text at 18px / 1.45. Source Sans Pro Regular. Specs first, short claims backed by a number.
Small text 14px for captions and secondary information.

Titles use Helvetica LT Pro Bold (helvetica-lt-pro). Body and buttons use Source Sans Pro (source-sans-pro). No italics. No all-caps headings.

Buttons

Primary action Secondary Outline black Outline blue

Every button is a 60px-radius pill. Primary is solid #487FFF. Hover only on desktop (from 1280px). Minimum width 120px.
