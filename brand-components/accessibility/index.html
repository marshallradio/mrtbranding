Accessibility

Every interface must be usable by keyboard, screen reader, and at 200% zoom.

Focus rings

2–3 px outline in Primary Blue or Ink, 2 px offset. Never remove focus styles.

Focused element

Touch targets

Minimum 44×44 px for all interactive elements.

Contrast

Body text ≥ 4.5:1. Large text and UI graphics ≥ 3:1. Do not rely on color alone for status.

Reading width

Keep body text ≤ 68 characters where practical. Long legal text uses the 726 px narrow column.

RTL

Arabic and RTL layouts mirror with logical properties (margin-inline, padding-inline, text-align start/end).
